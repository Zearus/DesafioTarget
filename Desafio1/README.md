# Desafio 1 — Cálculo de Comissão

## Descrição

O objetivo deste desafio é desenvolver um programa em **C#** capaz de ler um arquivo JSON contendo registros de vendas de um time comercial e calcular a comissão de cada vendedor.

Cada venda possui:

* Nome do vendedor;
* Valor da venda.

A comissão é calculada individualmente para cada venda de acordo com o valor vendido e, posteriormente, os valores das comissões são somados por vendedor.

## Como executar

Certifique-se de que o arquivo vendas.json esteja no diretório correto do projeto.

Depois, execute:

dotnet run

O programa irá ler automaticamente o arquivo vendas.json, processar as vendas e apresentar a comissão total de cada vendedor no console.
